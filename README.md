# Invest Agent

Локальный агент для управления российским инвестиционным портфелем с фокусом
на облигациях. Агент анализирует портфель, формирует объяснимые рекомендации и
может передавать заявки отдельному исполнителю только после явного одноразового
подтверждения владельца.

Пользовательский интерфейс — диалог с Codex в этом проекте. CLI ниже является
внутренним набором инструментов, который Codex использует для точных расчётов и
чтения портфеля.

## Текущий статус

Реализован фундамент безопасного MVP:

- машинно-читаемый инвестиционный мандат;
- доменная модель портфеля и торговой рекомендации;
- независимая проверка ограничений;
- криптографическая привязка подтверждения к точному пакету заявок;
- порт брокера только для чтения;
- нормализация официального ответа портфеля БКС;
- безопасная ротация refresh-токена в локальном приватном файле;
- проектный Codex-скилл инвестиционного агента;
- тесты критичных запретов.

Торгового адаптера и функции отправки заявок в текущей версии нет.

## Принципы безопасности

- аналитический процесс не получает торговый токен;
- ни одна заявка не исполняется из текста рекомендации;
- разрешены только лимитные заявки;
- изменение цены, количества или инструмента меняет отпечаток предложения и
  требует нового подтверждения;
- заблокированные инструменты и запрещённые классы активов нельзя включить в
  заявку;
- вывод денег, переводы активов, маржинальные и производные операции не входят
  в интерфейсы приложения.

## Локальное подключение БКС

Read-only refresh-токен хранится в `.local/secrets/` с правами `600`, а локальный
`.env` содержит только путь `INVEST_AGENT_TOKEN_FILE`. Оба пути исключены из Git.
Содержимое токена нельзя передавать в Codex, Git или вывод терминала:

```bash
uv run invest-agent portfolio --format json
```

После каждого обращения БКС ротированный refresh-токен атомарно записывается в
тот же приватный файл. `--token-file` остаётся доступен как явный временный
override.

После этого пользователь работает через Codex обычными фразами: «что у меня в
портфеле?», «куда вложить 50 тысяч?» или «оцени риск эмитента».

Детерминированный аудит текущей структуры, управляемого контура и позиционной
концентрации вызывается Codex-командой:

```bash
uv run invest-agent audit --format json
```

Аудит не является торговой рекомендацией и явно перечисляет показатели, которые
невозможно оценить без рыночного, кредитного и исторического обогащения.

Официальные карточки выпусков и эмитентов, текущая эффективная доходность,
дюрация, спреды и показатели торгов Московской биржи:

```bash
uv run invest-agent bonds --format json
```

Команда использует публичный read-only MOEX ISS. Данные могут приходить с
задержкой; отчёт сохраняет время получения, торговый timestamp и прямые URL
источников. Доходность MOEX не считается прогнозом и не заменяет кредитный
анализ.

## Ближайшие этапы

1. Read-only подключение БКС и сверка снимка ИИС.
